SVIMS Billing app - hosting files
1. Put ALL files in this folder at one web address (GitHub Pages or Netlify).
2. Open the address, sign in, then install: Edge -> ... menu -> Apps -> Install this site as an app (Chrome: install icon in the address bar).
Files: index.html (the app), manifest.webmanifest + sw.js + icon-192.png + icon-512.png (make it installable).
Replace icon-192.png / icon-512.png with your own logo (same sizes) if you like.
Apps Script: paste apps_script_Code.gs in the Google Sheet (Extensions > Apps Script) and deploy a New version.
